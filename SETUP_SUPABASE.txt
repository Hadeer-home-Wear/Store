إعداد موقع HADEER HOME WEAR ولوحة الإدارة
================================================

ملفات الموقع جاهزة للرفع إلى جذر مستودع GitHub Pages. لوحة الإدارة داخل نفس الموقع، واسم الدخول الظاهر هو Hadeer.

مهم: لا يمكن تفعيل دخول آمن أو حفظ المنتجات لكل الزوار قبل ربط Supabase. لا توجد خدمة خارجية تم إعدادها نيابة عنك من هذه الحزمة.

1) أنشئي مشروعًا في https://supabase.com/
2) افتحي SQL Editor > New query، والصقي محتوى supabase-setup.sql ثم شغّليه.
3) افتحي Authentication > Users وأنشئي مستخدم إدارة ببريدك الإلكتروني. عطّلي التسجيل العام للمستخدمين. استخدمي كلمة مرور قوية بدل 1994 لأن 1994 سهلة التخمين.
4) من Project Settings > API انسخي Project URL و anon/publishable key فقط. لا تستخدمي service_role key داخل الموقع.
5) افتحي index.html وعدّلي هذه القيم: SUPABASE_URL و SUPABASE_ANON_KEY و ADMIN_EMAIL (ضعي بريد حساب الإدارة الذي أنشأتيه في Supabase). لا تضعي كلمة المرور داخل أي ملف.
6) ارفعي كل محتويات مجلد HADEER_STORE إلى جذر المستودع، بما فيها index.html وملفات الصور وsupabase-setup.sql وملفات التعليمات.
7) من GitHub افتحي Settings > Pages > Deploy from a branch، واختاري main و /(root) ثم Save.
8) افتحي الموقع واضغطي «إدارة المنتجات». أدخلي اسم المستخدم Hadeer وكلمة المرور التي ضبطتيها لحساب Supabase.

بعد الإعداد، المنتجات والصور التي تضيفينها من لوحة الإدارة تحفظ في قاعدة البيانات وتظهر لجميع الزوار. الصور حتى 5MB.

واتساب الطلبات: 01063163074. يرسل الموقع اسم المنتج والسعر والمقاس واللون ورابط صورة المنتج داخل رسالة واتساب، لكن العميل يحتاج الضغط على إرسال داخل واتساب.

تنبيه أمني: اسم المستخدم Hadeer هو اسم دخول واجهة فقط؛ التحقق الحقيقي يتم عبر Supabase Auth. لا يمكن اعتبار كلمة المرور 1994 آمنة، لذلك استبدليها بكلمة قوية وفريدة قبل النشر.
